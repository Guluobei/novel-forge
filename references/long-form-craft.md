# 长篇骨架方法论（百万字的地基）

> 本文整理自 ima 知识库「小说写作知识库」「网文写作技巧」「网络小说创作指南」三库中的长篇创作方法论。
> 核心判断：**短篇靠一个精巧的点子，长篇靠一套能反复产出的机制。** 三十万字开始「空转」的书，问题从来不在文笔，在骨架。

## 一、核心循环：长篇的永动机

核心循环是支撑故事持续抓人的底层闭环。它要让读者在最短时间内搞清三件事：
**故事在讲什么、主角要干什么、追下去能得到什么情绪价值。**

| 作品 | 循环 |
|---|---|
| 《斗破苍穹》 | 遭遇强敌 → 被压制受辱 → 获得机缘 → 闭关修炼 → 当众打脸 → 新的强敌 |
| 《诡秘之主》 | 获得神秘知识 → 序列提升 → 新技能解锁 → 面临更高风险 → 理智与命运博弈 → 更大的秘密 |

「诡秘」多了一个**失控维度**——读者不只期待变强，还担心主角哪一步会迷失。

**自检三问**（写入 `framework.engine.loop`）：

1. 主角每次循环**获得了什么**？（成长 / 资源 / 情报）
2. 每次循环的**终点**是什么？（新挑战 / 新敌人 / 新地图）
3. 循环的**驱动力**是什么？（复仇 / 守护 / 求知 / 变强）

> 如果「获得」这一环是空的，读者三章后就会觉得主角在瞎忙。

## 二、故事引擎的四个驱动轮

四个轮子配比不同，书的气质就不同（写入 `framework.engine.drive_wheels`）：

| 引擎 | 参考配比 | 要点 |
|---|---|---|
| **实力提升** | 约 60% | 第一动力。境界要清晰，突破不是终点而是新循环的起点，每次突破后立刻设更强对手 |
| **世界扩展** | 约 20% | 塔状地图，每层有独立势力格局与终极 BOSS |
| **矛盾冲突** | — | 三层：外部（敌人挑衅/势力争斗/资源争夺）、内部（心魔/价值抉择/情感纠葛）、成长（瓶颈焦虑/失控风险） |
| **爽点释放** | — | 四步曲：压抑 → 积累 → 爆发 → 收尾（敌人震惊 + 获得奖励 + 埋新伏笔） |

> 纯实力引擎的书在 60 万字后必然单调；矛盾引擎不足的书，读者说不出「为什么还要看下去」。

## 三、延展性判断：这个点子能不能撑住一百万

判断标准不是「点子新不新」，是**延展性**：

1. 主角的「变强」能分出几个**可命名的档次**？（少于 5 档撑不住 50 万字）
2. 每一档能对应一个**不同的舞台/敌人形态**吗？
3. 除了「打赢」，有没有第二种读者期待的东西（**真相 / 选择 / 代价**）？

三问里挂掉两问，点子就要改造，不要硬写。

反面教材「异界短跑健将」：升级路线只有「跑得更快」，第三次提速读者就腻了。

## 四、可攀越的世界观：阶梯表

长篇能写长，第一功臣是**世界观自带阶梯**。都市文同样要有阶梯，只是换坐标轴：

- 地理阶梯：乡镇 → 县城 → 地级市 → 省会 → 直辖市 → 首都
- 财富阶梯：一万 → 几十万 → 几百万 → 千万 → 上亿
- 组织阶梯：小公司 → 行业新贵 → 上市公司 → 顶级财团

**关键原则**：每上一个台阶，敌人、资源、秘密同步升级。只换地图不换敌人质量，读者会立刻感到空转。

写入 `framework.ladder.steps`，每阶五要素：舞台 / 主角实力上限 / 该阶主要对手 / 该阶核心资源 / 该阶解开的秘密。
**哪一阶是空的，哪一阶将来就会水。**

## 五、难度梯度与情绪抑扬波

- **难度梯度**：每次提升 20%~30% 是黄金比例。不递增读者无聊，跳跃太大读者失去代入感。
- **情绪抑扬波**：抑 → 扬 → 更大的抑 → 更大的扬。

以「三年之约」为例：被退婚当众受辱（抑）→ 得药老、修焚诀、实力恢复（扬）→ 纳兰嫣然碾压、云岚宗步步紧逼（更大的抑）→ 三年期满当众击败（更大的扬）。

- 波动周期参考：**每 10-20 万字**一个完整的抑扬波。
- 检查：后一个抑点是否比前一个更狠？后一个扬点是否比前一个更解气？如果不是，读者会觉得「越来越平」。

## 六、节奏的呼吸法则（反直觉但极重要）

> **爽点给得越密，读者跑得越快。**
> 有本起点玄幻新书上架首订八千，两个月后追读率跌了一半，读者原话是「追不动了，太累了」——像坐一列没有刹车的过山车。

节奏的本质是**对比**：快因为有慢才显得快，高潮因为有平静才显得震撼。没有山谷就没有山峰。

两个能直接用的手法：

1. **铺垫精简，高潮放慢**。没用的铺垫（路人对话、环境描写、心理碎碎念）大刀阔斧删；到了打脸、逆袭、名场面反而要沉下来细写——神态、心理、现场反应、旁人震惊，慢慢铺开。
2. **只给半口糖**。情绪递进不要一次给满，给一半，剩下的吊着。

**呼吸章纪律**：统计连续 10 章的爽点数量，如果每章都有大爽点，强制插入 2-3 章的呼吸章（日常、信息整理、配角视角、伏笔回收）。

## 七、中期的三种死法

长篇真正的淘汰赛在 30 万字之后。

| 死法 | 表现 | 检验标准 |
|---|---|---|
| **空转** | 主角变强了却没有新挑战 | 每次升级后是否立刻设置了更强的对手？难度是否递增 20%-30%？ |
| **水** | 不是字数多，是没有新信息的重复 | 车轱辘话、重复已知信息、主角忙碌但不推进 |
| **人设崩** | 全靠灵感飞，中期高冷男主突然变舔狗 | 自己都圆不回来 |

## 八、中期三件套与认知线

**中期三件套**（写入 `framework.midgame`）——30 万字之后的弹药库：

1. 一个**开篇就埋下**的身世伏笔
2. 一段**被抹去的历史**
3. 一个**还没登场的势力阵营**

**循环的进化**（2024 年后的爆款趋势，写入 `midgame.cognitive_truths`）：

- 从「升级循环」到「**认知循环**」：收获不再是新技能，而是新的真相、新的选择、新的代价。
- 从「线性循环」到「网状循环」：同时面对多条规则线的约束，每次决策牵动多个变量。
- 从「可控循环」到「**失控隐喻**」：越升级风险越大，甚至可能失去自我。

> 给主角加一条认知线：每跑完两轮实力循环，解锁一个改变他世界观的真相。列出 5 个真相。
> 纯数值升级跑到 60 万字后，需要叠加第二层循环才能续命。

## 九、套娃与嵌套三幕式

- **套娃循环**：复用同一个故事模式，换汤不换药——框架不变，细节和情节换。《西游记》从头到尾一个循环：遇难 → 徒弟打不过 → 搬救兵 → 过关。**不重复内容，只重复模式。**
- **嵌套三幕式**：大幕里套小幕，每个大单元内部是完整三幕，每个小单元也是完整三幕。
- 分卷实用做法：先定总字数与分卷节点，每卷列 3-5 个关键剧情点，再补 **2 个备选转折**——这 2 个备用转折就是卡文时的救命绳。

**检查**：卷与卷之间是不是「换汤不换药」的套娃结构。如果是完全不相干的新故事，说明主线断了。

## 十、大纲的三种写法与「活大纲」

大纲不是合同，是**导航**。

| 写法 | 适用 |
|---|---|
| 正推 | 从设定出发，按阶梯表逐卷推进（体系型长篇） |
| 高潮反推 | 先定每卷高潮场面，再往回铺台阶（爽文/飞卢系） |
| 人物经历型 | 以主角人生阶段为轴串事件（都市/年代文） |

**活大纲**：定死主线节点和卷末状态，中间的「怎么走到」留白，写到哪儿再定。既不迷路，也不被大纲绑死。

> 反面教训：全靠灵感带着飞，写到中期必卡文，人设也崩。

## 十一、结局与完本

- **高潮泄气的两大原因**：爆得太早（能量提前释放完）或憋过头（铺垫太长，读者已疲劳）。
- **结局收放原则**：先想清楚最后一页希望读者记住什么——一个画面、一句话、还是一种「终于懂了」的感觉。这个终点坐标**决定了前文哪些细节值得写、哪些可以删**。
- **完本本身是竞争力**：超过 70% 的新人在签约前弃坑，能坚持到完本的不足 5%。

> 现在就写你的结局章（不需要能直接用，但要有）。写完回头看第一卷细纲，哪些是为这个结局服务的、哪些是废笔。

## 十二、九线设定（构思期的全面自查）

大纲分两部分：构架体系设定 + 主线分线设定。构架体系用「九线」一次铺完：

1. 主角智慧性格（价值观、信念、追求——决定他面对困境时的决策方式）
2. 配角炮灰（每个都要有性格、实力、背景故事）
3. 技能（主角技能独特且有成长性；常人技能负责真实感）
4. 伙伴（助力 + 情感寄托）
5. 装备（来历、传说、获取过程）
6. 冒险（主线推进的动力）
7. 身世（伸展性 + 伏笔功能）
8. 势力（门派/国家/组织，构成主要冲突）
9. 情感线（情感纠葛与成长助力）

> 每条不少于 3 个**具体**设定。不要写「性格：坚毅」，要写「被冤枉时第一反应是沉默而不是辩解，因为他十二岁那年辩解过一次，代价是母亲」。

## 十三、每 50-100 万字一次地图升级

游戏化世界观给了「换地图」这个最强续命工具：主角换地图后从零开始，所有读者体验重置。但**必须换敌人质量**，只换地图不换对手，就是空转。

## 十四、金手指：制造问题，而不是解决问题

- 低级金手指：遇到困难 → 金手指启动 → 问题解决。前三章爽，第十章腻，因为它在替主角过日子。
- 高级金手指：给主角的不是答案，是**一个更困难的选择**。读心术不是让主角全知，而是让他听见所有人的恶意，包括他不想听的。
- 好的金手指随时间成长、能开发新形态，而不是一开始就给满。

> 写出金手指的**三条限制**和**两个副作用**。写不出来，说明它是万能的，万能的东西不产生剧情。
