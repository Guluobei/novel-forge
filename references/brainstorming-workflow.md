# 构思协作方法论：从零到一个百万字框架

本文件定义「陪作者一步步把长篇想清楚」的完整流程。核心原则：

> **不替作者做决定，而是把每个决定拆成可选方案 + 利弊 + 后果，让作者选。**
> 每个阶段产出必须经作者确认才进入下一阶段。

篇幅承诺：**百万字起步**。这意味着框架必须能支撑 300-500 章、
至少 5-8 个剧情单元、主角 3 次以上的本质性转变。

> 本流程与 `references/long-form-craft.md`（长篇骨架方法论）配套使用：
> 本文负责「按什么顺序问」，long-form-craft 负责「每块内容怎么才算合格」。

---

## 阶段 0：判断起点（先问清，再动手）

不同起点走不同路径：

| 作者起点 | 首个问题 | 直接进入 |
|---|---|---|
| 只有题材（"都市高武"） | 你想讲一个关于什么的故事？ | 阶段 1 |
| 有一个情境/画面（"某人在地下听见晶体说话"） | 这个画面里最让你兴奋的是什么？ | 阶段 2 |
| 有人物（"一个不想被定价的拾荒者"） | 他最想得到什么？最怕失去什么？ | 阶段 1→2 |
| 有主题（"人被量化定价"） | 你想让读者读完记住什么？ | 阶段 2 |

**前置一步：定平台**。同一本书在番茄爆、在起点扑，是平台隐形规则不同。
先问「你打算发在哪」，因为它直接决定前三章的密度：

- 番茄：第一阶要在前 15 万字内跑完两轮循环，节奏必须快
- 起点：可以慢热，允许先铺设定与长期布局，第一阶放到 30 万字

平台确认后写入 `framework.platform.target`。开局没有平台没关系，但必须在写前三章之前定下来。

**铁律**：作者说"随便""你定"时，**不要替他定**。给 2-3 个差异明显的方案并说明各自会写出什么样的书。

## 阶段 1：故事内核（一句话能立住吗）

产出「内核卡」，四个必须回答的问题：

1. **主角是谁**（身份 + 一个具体处境，不是形容词堆砌）
2. **他想要什么**（贯穿全书的显性目标，要可验证：找到 X、成为 Y、毁掉 Z）
3. **什么在阻止他**（不只是反派，还包括规则、代价、他自己的缺陷）
4. **为什么是现在**（打破日常的催化剂事件）

判据：把答案压成一句话"**一个___的人，为了___，必须在___的情况下对抗___**"，读起来有张力才算过。

**常见失败**：目标太抽象（"变强""守护"）→ 追问"变强到能做什么具体的事"；
动机是外部强加的（"师父让他去的"）→ 追问"他自己图什么"。

### 本阶段必须补做的：延展性三问

内核立住之后立刻追问——**这个点子能不能撑到一百万？**
判断标准不是「点子新不新」，是延展性（写入 `framework.engine.extensibility`）：

1. 主角的「变强」能分出几个**可命名的档次**？（少于 5 档撑不住 50 万字）
2. 每一档能对应一个**不同的舞台/敌人形态**吗？
3. 除了「打赢」，有没有第二种读者期待的东西（**真相 / 选择 / 代价**）？

> 三问里挂掉两问，点子就要改造，不要硬写。
> 反面教材「异界短跑健将」：升级路线只有「跑得更快」，第三次提速读者就腻了。

## 阶段 1.5：核心循环与驱动轮（长篇的永动机）

**这一步是整条流水线最硬的一块**——凡是三十万字开始空转的书，问题都在这里，不在文笔。

### 核心循环（写入 `framework.engine.loop`）

核心循环是**能持续产出爽点、悬念、期待的闭环**，它让读者在最短时间搞清三件事：
故事在讲什么、主角要干什么、追下去能得到什么情绪价值。

参照：

| 作品 | 循环 |
|---|---|
| 《斗破苍穹》 | 遭遇强敌 → 被压制受辱 → 获得机缘 → 闭关修炼 → 当众打脸 → 新的强敌 |
| 《诡秘之主》 | 获得神秘知识 → 序列提升 → 新技能解锁 → 面临更高风险 → 理智与命运博弈 → 更大的秘密 |

必须回答三问：

1. 主角每次循环**获得了什么**？（成长 / 资源 / 情报）
2. 每次循环的**终点**是什么？（新挑战 / 新敌人 / 新地图）
3. 循环的**驱动力**是什么？（复仇 / 守护 / 求知 / 变强）

> **如果「获得」这一环是空的，读者三章后就会觉得主角在瞎忙。**

### 四驱动轮配比（写入 `framework.engine.drive_wheels`）

四个轮子配比不同，书的气质就不同。让作者给四个轮子打分（总和 100）：

| 引擎 | 参考 | 要点 |
|---|---|---|
| 实力提升 | 60% | 第一动力。突破不是终点而是新循环的起点，每次突破后立刻设更强对手 |
| 世界扩展 | 20% | 塔状地图，每层有独立势力格局与终极 BOSS |
| 矛盾冲突 | — | 三层：外部 / 内部（心魔、价值抉择）/ 成长（瓶颈焦虑、失控风险） |
| 爽点释放 | — | 四步曲：压抑 → 积累 → 爆发 → 收尾（敌人震惊 + 奖励 + 新伏笔） |

> 纯实力引擎的书在 60 万字后必然单调；矛盾引擎不足的书，读者说不出「为什么还要看下去」。
> **哪个轮子最弱，就在下一卷专门加一条对应的线。**

## 阶段 2：主题与内核矛盾（长篇的脊椎）

百万字不靠情节撑，靠**一个反复被追问的问题**撑。

产出「主题卡」：

- **主题句**：一个没有标准答案的问题（如"人被明码标价之后，还剩下什么是自己的？"）
- **正题**：主角一开始相信的答案
- **反题**：世界给出的相反答案（由反派/环境承载）
- **合题**：全书结尾主角给出的、付出了代价的答案

检验：主题必须在**每一卷都换一种形式被追问**，而不是只在结尾喊口号。
反派必须是主题的最强论证者——他的答案是"世界就是这样"，且他是对的但不是全部。

**升级检查（来自资料）**：最高级的冲突是「**正义与正义的碰撞**」——双方的正义各有支撑、不可调和
（主角坚持"不牺牲任何一个无辜者"，反派坚持"牺牲少数换取大局"）。
如果反派只是"单纯坏"，回去重做。

## 阶段 3：人物关系网（不是人设表，是力场）

产出「关系网」：主角 + 4-8 位核心角色，每人标注：

| 字段 | 要求 |
|---|---|
| 与主角的关系 | 不是标签（"好友"），是**力的方向**（他推主角往前/往哪拐） |
| 他自己的目标 | 必须与主角目标有交集或冲突，不能只是"帮主角" |
| 他承载的主题面 | 他对主题句的答案是什么 |
| 他的转变 | 长篇中他要不要变、何时变 |
| 声线锚点 | 3 个特征词，保证对话可盲测辨识 |

**配角工具化是长篇头号慢性病**：每个核心配角都要有一件"主角不在场时他自己在做的事"。

### 本阶段的两个开关（来自资料）

- **让配角被记住的两个开关**：挑衅主角的配角会被记住；小瞧主角的配角也会被记住。
- **给配角加一个反差细节**更活（反派喜欢吃甜食）。
- **主角必须有自我冲突**：好主角身上有两种互相打架的特质。
  例：《第一御兽师》肖星宇心智成熟杀伐果断，但融合记忆后又"鲜衣怒马少年郎"，在儿女情长上会失去理性。
- **人设落地的三个动作**：对话、动作、**内心**。内心不写，主角就是"木偶人"。

### 九线自查（覆盖构架体系，避免构思有盲区）

除了核心关系网，构架体系还应一次性铺完「九线」，每条 ≥3 个**具体**设定：

1. 主角智慧性格（价值观/信念/追求——决定他面对困境的决策方式）
2. 配角炮灰（每个都要有性格、实力、背景故事）
3. 技能（主角技能独特且有成长性；常人技能负责真实感）
4. 伙伴（助力 + 情感寄托）
5. 装备（来历、传说、获取过程）
6. 冒险（主线推进的动力）
7. 身世（伸展性 + 伏笔功能）
8. 势力（门派/国家/组织，构成主要冲突）
9. 情感线（情感纠葛与成长助力）

> 不要写「性格：坚毅」，要写「被冤枉时第一反应是沉默而不是辩解，因为他十二岁那年辩解过一次，代价是母亲」。

### 金手指必答（写入内核或人物卡）

- 写出金手指的**三条限制**和**两个副作用**。写不出来，说明它是万能的，万能的东西不产生剧情。
- 高级金手指给主角的不是答案，是**一个更困难的选择**（读心术不是全知，是听见所有人的恶意，包括他不想听的）。
- 金手指要**随时间成长、能开发新形态**，而不是一开始就给满。

## 阶段 4：百万字结构（分卷与单元）

产出「结构蓝图」，三层：

**第一层：幕（3 幕）**
- 第一幕（约 1-30%）：建立日常 → 打破 → 主角被迫上路
- 第二层（约 30-75%）：反复碰壁 → 中点（假胜利/假失败）→ 一切失去
- 第三幕（约 75-100%）：终极对决 → 新日常

**第二层：卷（5-8 卷）**每卷必须有：
- 卷内目标（本卷要达成什么，可验证）
- 卷末高潮（强度高于上一卷）
- 主角的**本质变化**（不是变强，是"他对某件事的看法变了"）
- 主题的新问法（这一卷在追问主题句的哪个侧面）

> 分卷实用做法：先定总字数与分卷节点，每卷列 **3-5 个关键剧情点**，再补 **2 个备选转折**——
> 这 2 个备用转折就是卡文时的救命绳。
>
> **检查**：卷与卷之间是不是「换汤不换药」的套娃结构。
> 如果是完全不相干的新故事，说明主线断了。（套娃 = 复用同一模式，换细节不换框架，《西游记》就是典型。）

**第三层：剧情单元（每卷 20-40 章，含 2-4 个单元）**
每个单元 = 一个完整的"诱因 → 升级 → 代价 → 收获"闭环。

### 本阶段新增：阶梯表（写入 `framework.ladder`）

长篇能写长，第一功臣是**世界观自带阶梯**。都市文同样要有阶梯，只是换坐标轴：

- 地理阶梯：乡镇 → 县城 → 地级市 → 省会 → 直辖市 → 首都
- 财富阶梯：一万 → 几十万 → 几百万 → 千万 → 上亿
- 组织阶梯：小公司 → 行业新贵 → 上市公司 → 顶级财团

画出 **5-7 阶**的阶梯表，每阶五要素：
**舞台 / 主角实力上限 / 该阶主要对手 / 该阶核心资源 / 该阶解开的秘密**。

> **关键原则**：每上一个台阶，敌人、资源、秘密同步升级。
> 只换地图不换敌人质量，读者会立刻感到空转。**哪一阶是空的，哪一阶将来就会水。**

### 本阶段新增：节奏与情绪波（写入 `framework.rhythm`）

- **难度梯度**：每次提升 **20%~30%** 是黄金比例。不递增读者无聊，跳跃太大读者失去代入感。
- **情绪抑扬波**：抑 → 扬 → 更大的抑 → 更大的扬。周期参考 **每 10-20 万字一轮**。

以「三年之约」为例：被退婚当众受辱（抑）→ 得药老、修焚诀、实力恢复（扬）→
纳兰嫣然碾压、云岚宗步步紧逼（更大的抑）→ 三年期满当众击败（更大的扬）。

> 检查：后一个抑点是否比前一个更狠？后一个扬点是否比前一个更解气？
> 如果不是，读者会觉得「越来越平」。

- **呼吸法则（反直觉但极重要）**：**爽点给得越密，读者跑得越快。**
  节奏的本质是对比——没有山谷就没有山峰。
  两个手法：① 铺垫精简，高潮放慢（打脸/逆袭/名场面反而要沉下来细写）；
  ② 只给半口糖（情绪递进不要一次给满，给一半，剩下的吊着）。
  纪律：如果连续 10 章每章都有大爽点，**强制插入 2-3 章呼吸章**（日常、信息整理、配角视角、伏笔回收）。

**爽点节奏承诺**（写进蓝图，供后期核对）：
每 3000 字小爽点 | 每 10000 字中爽点 | 每 30000-50000 字大爽点 | 每章末必留钩子

### 本阶段新增：中期弹药库（写入 `framework.midgame`）

长篇真正的淘汰赛在 30 万字之后。**在构思期就把这些埋好**，否则中期必崩：

- 「**中期三件套**」：一个开篇就埋下的身世伏笔 / 一段被抹去的历史 / 一个还没登场的势力阵营
- **认知线五真相**：每跑完两轮实力循环，解锁一个改变主角世界观的真相，列出 5 个。
  纯数值升级跑到 60 万字后，需要叠加第二层循环才能续命。

> 中期的三种死法：**空转**（变强了却没新挑战）、**水**（没有新信息的重复）、**人设崩**（全靠灵感飞）。

## 阶段 5：信息揭示节奏（长篇最易崩的一环）

产出「揭示表」：列出全书的重大秘密，每个标注：

| 秘密 | 计划揭示位置（卷/章） | 由谁揭示 | 揭示前的铺垫埋点 |
|---|---|---|---|

**铁律**：
- 秘密必须有**至少 3 处前置铺垫**，否则读者觉得突兀
- 主角金手指的**代价**必须早于**真相**揭示（先让读者心疼，再让读者震惊）
- 每卷结束前，至少回收 1 个前期伏笔，同时新埋 1-2 个——保持"欠债感"
- 信息差是悬念的燃料：读者和主角一起知道一半，线索交替出现，**从不一次性给完**

## 阶段 6：开篇设计（最后才做，但最重要）

框架清楚后再定前三章。因为前三章的任务不是"讲故事开始"，
而是**用最快速度让读者确认"这本书值得追"**：

1. 第 1 章：主角处境 + 一个具体困境 + 金手指/变数的**征兆**（不解释）
2. 第 2 章：冲突升级，主角做出第一个有代价的选择
3. 第 3 章：兑现第一个小爽点 + 抛出贯穿性悬念
4. 全章末必留钩子；开篇 500 字内必须出现钩子

### 黄金三章硬清单（来自资料，写完逐条打勾，超三条打叉就重写）

**90% 的读者在前三章决定是否继续。第一章点火，第二章加油，第三章定向。**

- **开头 100 字必须是钩子**。三种高效开头：悬念式 / 冲突式 / 震惊式。
  **铁律**：不要从环境、天气、家族史开始——直接写人、写事、写冲突。
- **第一章**（点火）：3000 字内至少给一个爽点。三种模式：困境逆袭型 / 身份隐藏型 / 系统降临型。
  **别憋大招，最好的牌打在第一章结尾。**
- **第二章**（加油）：世界观要「融」不要「堆」——通过对话、冲突、主角行动呈现
  （主角不知道货币叫什么，就让他问路人、购物、被人嘲讽）。章末必须埋钩子。
- **第三章**（定向）：让主角目标清晰、主线显现。常见桥段：打脸反派、初展实力、获得认可、立下宏愿。

自查清单：

- [ ] 第一章末：金手指是否已出现或强暗示？
- [ ] 第一章：是否至少一个爽点？
- [ ] 第一章：主角性格是否立住、是否有代入感？
- [ ] 第一章：章末是否留了悬念？
- [ ] 第三章末：故事大方向是否清晰？
- [ ] 第三章末：主角目标是否让读者知道？
- [ ] 第三章末：是否有一个让人印象深刻的场面？

**练法**：用三种开头各写一次第一章开头 100 字，挑最扎手的那版。

## 阶段 7：门面（书名 / 简介 / 封面）

写入 `framework.platform`：

- **书名公式**（番茄）= 关键词 + 爽点 + 题材。别玩文艺——三秒说不清题材就输了。
- **简介四要素**：主角身份反差 + 核心冲突 + 爽点关键词 + 结局走向。
- 按公式写 **5 个书名、3 版简介**，做「三秒测试」——扫一眼能否说清「讲什么、爽在哪」。

详见 `references/platform-guide.md`。

## 全稿自查（框架完成后、动笔前跑一遍）

> 完整版见 `references/platform-guide.md` 第七节。至少确认结构层与人物层：

**结构层**
- [ ] 核心循环能否一句话说清？每轮循环的「获得」是否具体？
- [ ] 难度是否每次递增 20%-30%？
- [ ] 每 10-20 万字是否有一个完整抑扬波？
- [ ] 每 50-100 万字是否有地图升级？
- [ ] 每一卷是否有独立的势力格局和终极 BOSS？

**人物层**
- [ ] 主角有没有互相打架的两种特质？长期目标是否明确？
- [ ] 金手指有没有三条限制、两个副作用？
- [ ] 反派的动机写出来，你自己觉得有道理吗？

## 协作规范（Claude 必须遵守）

1. **一次只推进一个阶段**，产出后用提问确认，不连跳
2. **每个阶段给出 2-3 个差异方案**，说明各自会写出什么样的书（气质/节奏/受众差异），而不是给一个"标准答案"
3. **主动指出风险**：如果作者的选择会导致后期难以为继（如金手指过强/无代价、反派动机单薄、
   目标不可验证、阶梯表不到 5 阶、核心循环「获得」环为空、缺中期三件套），
   必须当场说明理由并给出修正方向
4. **记录否决项**：作者否掉的方案要记入 `framework` 的 rejected 列表，避免反复提同一个被否过的方案
5. **框架是可改的**：写作中发现问题，回到对应阶段修订，而不是硬写下去
6. **绝不跳过阶段 1-1.5 直接写章节**：没有内核、核心循环与主题，章节写得再漂亮也是无效功
7. **用 `framework audit` 收口**：每个阶段写完跑一次体检，看到告警就回去补，不要带着红灯往下走
